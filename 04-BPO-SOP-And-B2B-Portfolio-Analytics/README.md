# 04 — Cross-Departmental Complaint Resolution SOP & B2B Portfolio Governance

## Overview
Developed during the Enterprise Semester at **U&I Logistics Corporation**:
1. **Workstream A — Cross-Departmental Complaint Resolution SOP**: Audited 15 operational procedures across Sales & CS, Ocean Freight, Bonded Warehousing, Customs Brokerage, and Fleet Dispatch; designed a standardized **Swimlane SOP Flowchart**, **5W1H Call Logging Protocol**, and inter-departmental SLA escalation matrix.
2. **Workstream B — Quantitative B2B Customer Portfolio Screening (Weighted Scoring Model - WSM)**: Python analytics scripts and visual matrices evaluating 4 B2B client archetypes against a **1,163.52B VND** revenue baseline (Client A = 97/100, +22B VND gross profit; Client D = 75/100; Client B = 50/100; Client C = 35/100).
